Rounds

Split the event into rounds

Off — one board for the whole event, highest score leads. On — the board gets a “this round” view and you can start a new round at any time.

🔴 Stations never wait for this button. Players can start at any time, no matter when a round changes. “Start a new round” draws a line on the board — it does not open a gate.
· A score belongs to the round the player started in, not the one they finished in, so anyone who starts before the line and finishes after it stays in the round they saw when they stepped up.

Pause scoring is for the announcement only — numbers stop moving while the host reads the names. Every station shows the ⏸ screen at the same time so no one hands a station to a player whose run would not count. Rounds never advance on a timer — only when someone presses the button.
Clearing asks for confirmation and records who did it. Past runs are kept and stay visible under Runs.

How combined standings are worked out

By rank — each game’s placing turns into points, then the points are added (table below). By score — raw scores from every game are added directly, which lets the game with the bigger numbers decide the outcome.
