ข้อ 3 — ขอบเขตความร่วมมือ

3.1 นักพัฒนาจะพัฒนา/ส่งเกมเพื่อเผยแพร่บนแพลตฟอร์ม ตามมาตรฐานในข้อ 4 และรายละเอียดต่อเกมใน ใบสั่งงาน (SOW) แต่ละฉบับ (ภาคผนวก ง.)

3.2 ROPZ ให้สิทธิ์นักพัฒนาใช้ Base Kit และ SDK เพื่อวัตถุประสงค์ตามสัญญานี้เท่านั้น (สิทธิ์ใช้แบบไม่ผูกขาด เพิกถอนได้ ห้ามโอนต่อ)

3.3 ROPZ มีดุลยพินิจในการจัดวาง/จัดหมวด/หมุนเวียน/นำเกมออกจากพอร์ทัล (rotation, featuring, takedown) ตามเงื่อนไขในสัญญา

3.4 สัญญานี้ ไม่ผูกขาด เว้นแต่ระบุไว้เป็นอย่างอื่นใน SOW — [เลือก: ผูกขาด / ไม่ผูกขาด ต่อเกม]

ข้อ 4 — มาตรฐานทางเทคนิคและการส่งงาน

นักพัฒนาต้องส่งเกมที่ผ่านเกณฑ์ Submission Gate ทั้งหมด (ภาคผนวก ข.):

4.1 ขนาดบิลด์ — first-load ≤ 25 MB (บีบแล้ว), wasm ≤ 10 MB, data ≤ 15 MB · เปิด Brotli · เป็น Release build

4.2 SDK & Loop — เรียก /game/v1 เวอร์ชันปัจจุบันตามลำดับ init → start → finish → reward โดยฝั่งเซิร์ฟเวอร์เป็นผู้ตัดสิน (server-authoritative)

4.3 Anti-cheat (บังคับ) — ใช้ nonce / clientHash, ยืนยันผล reward แบบ server-to-server (HMAC), และ ห้ามแจก/คำนวณเงินหรือรางวัลฝั่ง client โดยเด็ดขาด

4.4 การแสดงผล — เต็ม container 100%, orientation ตรง, ไม่ทับแถบผู้เล่น, รองรับทั้ง touch และ mouse

4.5 Metadata — แนบ manifest ครบ: game id, title, category, tags, thumbnail ตามสเปก, และ partner/ref id สำหรับ attribution

4.6 Telemetry — ส่ง event มาตรฐาน (session start/end, level clear ฯลฯ) เข้าระบบวัดผลของ ROPZ

4.7 การอัปเดต — ส่งเวอร์ชันใหม่ผ่าน flow ที่กำหนด รองรับ rollback · ROPZ ระงับเวอร์ชันที่ไม่ผ่านเกณฑ์ได้

ข้อ 5 — ทรัพย์สินทางปัญญา (IP)

5.1 เกมของนักพัฒนา — นักพัฒนายังคงเป็นเจ้าของ IP ในเกมที่ตนสร้าง โดยให้สิทธิ์ ROPZ เผยแพร่/ทำซ้ำ/แสดง/โปรโมตบนแพลตฟอร์มตลอดอายุสัญญา (ไม่ผูกขาด ทั่วโลก เพื่อการดำเนินแพลตฟอร์ม)

5.2 RO IP — ใช้ได้เมื่อมีข้อตกลงสิทธิ์ (T0–T4 royalty ข้อ 6.3) เป็นลายลักษณ์อักษรเท่านั้น ห้ามใช้ตัวละคร/ชื่อ/งานศิลป์ RO นอกขอบเขต

5.3 นโยบายงานศิลป์ AI — งานที่เป็น ตัวละคร/IP ของ RO ต้องวาดโดยมนุษย์ ส่วนที่ AI ช่วยได้ต้องอยู่ในโซนที่อนุญาตและผ่านเกณฑ์คุณภาพภาพ

5.4 Tier-2 Import (สำคัญ) — นักพัฒนา รับรองว่ามีสิทธิ์/ไลเซนส์ครบถ้วน และต้อง ถอด SDK / โฆษณา / โค้ดของบุคคลที่สาม (เช่น Poki, CrazyGames) ออกทั้งหมด ก่อนส่ง — ROPZ ตรวจและปฏิเสธได้หากพบส่วนตกค้าง

5.5 นักพัฒนารับรองว่าเกมไม่ละเมิด IP ของผู้ใด และจะชดใช้ ROPZ หากมีการเรียกร้อง (ข้อ 11)

ข้อ 7 — Attribution และการป้องกันการทุจริต

7.1 First-touch ต่อผู้เล่น — เมื่อผู้เล่นถูกระบุแหล่งที่มาครั้งแรก จะผูกกับบัญชีนั้นตลอด (ไม่นับใหม่รายเซสชัน)

7.2 Ref window — ลิงก์ ref มีอายุ [30 / 60 / 90] วัน หลังจากนั้นถือเป็น organic (ของ ROPZ)

7.3 Fraud gate — รายได้ dev-brought อยู่สถานะ PENDING จนกว่าจะผ่านเกณฑ์: นับเฉพาะ Quality User · ตรวจจับความผิดปกติ (spike/bot) → ระงับตรวจสอบ · ระบบฝั่งเซิร์ฟเวอร์ ROPZ ชี้ขาด แก้ค่า attribution ไม่ได้

7.4 การทุจริต (traffic ปลอม, incentivized เกินกำหนด, bot, self-click) เป็นเหตุให้ ริบรายได้ส่วนนั้นและอาจเลิกสัญญา (ข้อ 14)

10.2 ห้ามเด็ดขาด — เนื้อหาผิดกฎหมาย การพนัน กลไก แลก/ถอนเป็นเงินสดจริง (cash-out) หรือสิ่งที่อาจเข้าข่ายการพนันตามกฎหมายไทย (รางวัลต้องอยู่ในระบบ/แจกทางเดียวเท่านั้น)
